PDF Canvas Editor — Local Version
=================================

How to use
1. Extract the ZIP file.
2. Double-click index.html to open it in Chrome or Edge.
3. Click Open PDF and choose your PDF file.
4. Add text or photos, then drag and resize them.
5. To paste a screenshot:
   - Press Windows + Shift + S and capture an area.
   - Click the PDF editor workspace.
   - Press Ctrl + V.
6. Click Export PDF to download the edited PDF.

Extra PDF tools
- Compress: choose a PDF, select the compression level, and download it.
- Merge: choose two or more PDFs, change their order, and merge them.
- Split: preview every page, remove unwanted pages, then combine the kept pages
  into one PDF or download them as separate PDFs inside a ZIP file.
- Page numbers: in PDF Editor, click Page No. and drag the number to any
  position. The same position is applied consistently to every page.
- Create PDF: mix PDF, DOCX, XLSX/XLS/CSV, JPG, PNG and WebP files, preview
  every generated page, reorder or remove pages, then download one PDF.
- Scan to Text: run English or Burmese + English OCR on scanned PDFs and
  photos, edit the extracted text, then copy it or download a TXT file.
- Formatted OCR: preserve two-column layouts without the source background,
  edit the clean result, and download it as Word or PDF.

Notes
- An internet connection is required when opening the editor because the PDF processing libraries load from a CDN.
- Your PDF, photos, and edits are processed inside your browser.
- For best results, use the latest Chrome or Microsoft Edge.
